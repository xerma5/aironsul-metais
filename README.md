# AironSul Metais

Site institucional da AironSul Metais, fundição localizada em Araquari, Santa Catarina.

## Edição

- `index.html`: conteúdo e estrutura da página
- `styles.css`: identidade visual e responsividade
- `script.js`: menu, galeria, vídeos e interações
- `company.js`: dados centralizados da empresa
- `images/`, `videos/` e `brand/`: arquivos de mídia

O site é publicado automaticamente pelo GitHub Pages a partir da branch `main`.
